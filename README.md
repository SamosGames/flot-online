# Морской бой онлайн

Браузерная многопользовательская игра о морских сражениях. Управляйте кораблём, уклоняйтесь от торпед и сражайтесь за победу.

## Сборка

Проект использует Rust, WebAssembly и Trunk:

```bash
make rustup
make trunk
cd client && make release
cd ../server && make run_release
```

После запуска откройте https://localhost:8443/.

## Разработка

Типы кораблей, оружия, самолётов, препятствий и предметов находятся в `common/src/entity/_type.rs`.

## Лицензии и attribution

Проект основан на открытом исходном проекте морской игры. Исходные лицензии, товарные знаки и требования правообладателя сохраняются. Название и товарный знак Mk48.io принадлежат Softbear, Inc.
