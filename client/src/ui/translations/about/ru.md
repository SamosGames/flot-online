# Описание
«Флот Онлайн» от SamosGames — многопользовательский морской бой. Собирайте ящики, топите соперников и улучшайте свой корабль. На выбор есть [# кораблей](/ships/) и [#](weapons) типов оружия, разделённых на [# уровней силы](/levels/).

Подробные правила игры находятся на [странице помощи](/help/).
