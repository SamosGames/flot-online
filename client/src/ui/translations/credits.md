# Об игре
- «Флот Онлайн» создан SamosGames на Rust с использованием [открытого программного обеспечения, звуковых эффектов CC0 и оригинальной музыки Tim Beek](/licensing/).
- Текстуры смоделированы и отрендерены в [Blender](https://www.blender.org/) с использованием [справочных изображений](/references/), а также открытых текстур [песка](https://opengameart.org/content/simple-seamless-tiles-of-dirt-and-sand-sand2png), [травы](https://opengameart.org/content/grass-textureseamless-2d) и [снега](https://opengameart.org/content/seamless-snow-texture-0).
- Проект основан на открытом коде Softbear Studios и распространяется по лицензии AGPL-3.0-or-later.
- Геолокация IP предоставляется [DB-IP](https://db-ip.com) и [IPinfo](https://ipinfo.io/).
